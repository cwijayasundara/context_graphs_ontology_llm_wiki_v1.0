# FP4 Precision

FP4 (4-bit floating point) precision is a low-precision numerical format used in AI computing to accelerate inference and reduce memory requirements. The NVIDIA DGX SuperPOD with Blackwell Ultra GPUs offers FP4 precision to supercharge token generation for AI applications.
