# Open-Source Physics Engine for Robotics Simulation

Newton is an open-source physics engine for robotics simulation, developed collaboratively by NVIDIA, Google DeepMind, and Disney Research. It is accelerated by the NVIDIA Warp framework and compatible with MuJoCo. Powered by Newton, MuJoCo will accelerate robotics machine learning workloads by more than 70x compared with MuJoCo's existing GPU-accelerated simulator, MJX. This represents a major advancement in open-source simulation infrastructure for robotics research.
