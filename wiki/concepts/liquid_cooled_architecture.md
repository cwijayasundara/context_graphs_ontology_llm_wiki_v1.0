# Liquid-cooled Architecture

Liquid-cooled architecture is a data center cooling approach using liquid coolants to dissipate heat from high-density computing systems. The DGX GB300 system uses a rack-scale, liquid-cooled architecture designed for real-time agent responses on advanced reasoning models.
