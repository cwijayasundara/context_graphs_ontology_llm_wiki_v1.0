# NVIDIA Omniverse Cloud

NVIDIA Omniverse Cloud is a platform for simulating and testing physical AI solutions using digital twins. HUMAIN will deploy Saudi Arabia’s first Omniverse Cloud as part of the AI infrastructure partnership with NVIDIA.
