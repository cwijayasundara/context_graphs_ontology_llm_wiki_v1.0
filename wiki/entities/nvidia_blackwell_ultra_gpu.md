# NVIDIA Blackwell Ultra GPU

NVIDIA Blackwell Ultra GPU is the latest generation of NVIDIA data center GPUs powering the DGX SuperPOD. It delivers FP4 precision and faster AI reasoning for agentic AI applications. DGX GB300 systems feature 72 NVIDIA Blackwell Ultra GPUs per system connected by fifth-generation NVLink technology.
