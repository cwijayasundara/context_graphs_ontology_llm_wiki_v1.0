# MaxText

MaxText is an advanced framework for scaling large models across massive GPU clusters. It uses optimizations codeveloped with NVIDIA to enable efficient training on tens of thousands of GPUs. Google Cloud and NVIDIA collaborated to optimize MaxText to run efficiently on NVIDIA GPUs at scale.
