# NVIDIA DGX GB300

NVIDIA DGX GB300 is a liquid-cooled AI system featuring NVIDIA Grace Blackwell Ultra Superchips with 36 NVIDIA Grace CPUs and 72 NVIDIA Blackwell Ultra GPUs per system. It uses a rack-scale, liquid-cooled architecture designed for real-time agent responses on advanced reasoning models. Each system features 72 NVIDIA ConnectX-8 SuperNICs delivering up to 800Gb/s networking speeds and 38TB of fast memory. DGX GB300 systems deliver up to 70x more AI performance than AI factories built with NVIDIA Hopper systems.
