# NVIDIA Spectrum-X Ethernet

NVIDIA Spectrum-X Ethernet is NVIDIA's Ethernet networking solution for AI data centers. It is used alongside Quantum-X800 InfiniBand in DGX SuperPOD configurations to accelerate performance, efficiency, and security in massive-scale AI data centers.
