# NVIDIA Grace CPU

NVIDIA Grace is an Arm Neoverse-based CPU used in the GB300 NVL72 rack-scale solution. The GB300 NVL72 connects 72 Blackwell Ultra GPUs and 36 NVIDIA Grace CPUs.
