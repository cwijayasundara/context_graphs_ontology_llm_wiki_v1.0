# NVIDIA HGX B300 NVL16

The NVIDIA HGX B300 NVL16 is a system in the Blackwell Ultra platform featuring:
- 11x faster inference on large language models
- 7x more compute
- 4x larger memory

Compared with the Hopper generation, it delivers breakthrough performance for the most complex workloads, such as AI reasoning.
