# NVIDIA ConnectX-8 SuperNIC

NVIDIA ConnectX-8 SuperNIC provides 800 Gb/s of data throughput for each GPU in Blackwell Ultra systems. It delivers best-in-class remote direct memory access capabilities to enable AI factories and cloud data centers to handle AI reasoning models without bottlenecks.
