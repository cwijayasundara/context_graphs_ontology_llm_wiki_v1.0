# NVIDIA RTX PRO 6000 Blackwell Server Edition GPU

The NVIDIA RTX PRO 6000 Blackwell Server Edition GPU is a universal data center GPU built on the NVIDIA Blackwell architecture. It is designed for powering AI factories and accelerating demanding enterprise AI workloads, including multimodal AI inference, physical AI, design, scientific computing, graphics, and video applications. It serves as the core GPU for NVIDIA RTX PRO Servers.
