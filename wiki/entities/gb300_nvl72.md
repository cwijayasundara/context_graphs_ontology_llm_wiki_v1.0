# NVIDIA GB300 NVL72

The NVIDIA GB300 NVL72 is a rack-scale solution that connects 72 Blackwell Ultra GPUs and 36 Arm Neoverse-based NVIDIA Grace CPUs in a rack-scale design, acting as a single massive GPU built for test-time scaling.

Key features:
- 72 Blackwell Ultra GPUs
- 36 NVIDIA Grace CPUs
- 1.5x more AI performance than GB200 NVL72
- Available on NVIDIA DGX Cloud
- Used in NVIDIA DGX SuperPOD with DGX GB300 systems

Expected availability: second half of 2025.
