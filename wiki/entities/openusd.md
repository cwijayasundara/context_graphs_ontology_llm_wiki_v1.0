# OpenUSD

OpenUSD (Universal Scene Description) is an open-source framework for exchanging 3D graphics data. Intrinsic demonstrated an early OpenUSD framework streaming connection between Intrinsic Flowstate and NVIDIA Omniverse, enabling real-time visualization of robot workcells across platforms.
