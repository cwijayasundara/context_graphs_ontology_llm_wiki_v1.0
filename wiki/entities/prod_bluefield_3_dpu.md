# NVIDIA BlueField-3 DPU

NVIDIA BlueField-3 DPUs are data processing units included in NVIDIA RTX PRO Servers. They offload infrastructure tasks from CPUs to improve data center efficiency and performance. BlueField DPUs are also a core component of the NVIDIA Enterprise AI Factory validated design.
