# NVIDIA BlueField-3 DPU

NVIDIA BlueField-3 DPU (Data Processing Unit) is NVIDIA's infrastructure compute platform. Eighteen BlueField-3 DPUs pair with NVIDIA Quantum-X800 InfiniBand or NVIDIA Spectrum-X Ethernet in DGX GB300 systems to accelerate performance, efficiency, and security. Each DGX B300 system includes two BlueField-3 DPUs.
