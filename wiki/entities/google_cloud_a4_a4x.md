# Google Cloud A4 / A4X VMs

Google Cloud A4 and A4X are virtual machine instances powered by NVIDIA GPUs. A4 VMs are powered by NVIDIA B200 GPUs (Blackwell), and A4X VMs are powered by NVIDIA GB200 GPUs. Google Cloud became the first cloud provider to offer both B200- and GB200-based instances. A4 is generally available, with A4X coming soon.
