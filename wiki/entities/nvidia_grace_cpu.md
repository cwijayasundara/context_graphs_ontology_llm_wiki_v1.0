# NVIDIA Grace CPU

NVIDIA Grace CPU is NVIDIA's data center CPU. The DGX GB300 system includes 36 NVIDIA Grace CPUs paired with 72 NVIDIA Blackwell Ultra GPUs in the Grace Blackwell Ultra Superchip configuration.
