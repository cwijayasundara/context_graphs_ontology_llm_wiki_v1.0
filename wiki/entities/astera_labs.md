# Astera Labs

Astera Labs is a connectivity solutions company building on its history of close collaboration with NVIDIA to add purpose-built connectivity solutions for the NVLink Fusion ecosystem. It provides low-latency and high-bandwidth scale-up interconnects with native support for memory semantics to maximize AI server utilization and performance.
