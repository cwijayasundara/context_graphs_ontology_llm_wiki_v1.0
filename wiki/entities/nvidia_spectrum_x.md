# NVIDIA Spectrum-X

NVIDIA Spectrum-X is an Ethernet networking solution from NVIDIA featuring switches with co-packaged optics. It is part of NVIDIA's end-to-end networking platform delivering up to 800Gb/s of throughput, supporting AI factories built with NVIDIA NVLink Fusion.
