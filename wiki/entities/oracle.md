# Oracle

Oracle is a partner of NVIDIA. The companies announced integration between NVIDIA accelerated computing and inference software with Oracle's AI infrastructure. NVIDIA Blackwell cloud instances are available on Oracle Cloud Infrastructure. Oracle is also a partner in the Stargate UAE project alongside G42, OpenAI, SoftBank Group, and Cisco.
