# NVIDIA Quantum-X800 InfiniBand

NVIDIA Quantum-X800 InfiniBand is a networking platform that integrates with Blackwell Ultra systems. It provides 800 Gb/s of data throughput for each GPU in the system through an NVIDIA ConnectX-8 SuperNIC, delivering best-in-class remote direct memory access capabilities to enable AI factories and cloud data centers to handle AI reasoning models without bottlenecks.
