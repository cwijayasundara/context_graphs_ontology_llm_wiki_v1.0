# NVIDIA Dynamo

NVIDIA Dynamo is an open-source inference software library unveiled by NVIDIA in March 2025 at GTC. It is designed to accelerate and scale AI reasoning models in AI factories at the lowest cost and with the highest efficiency. It is the successor to the NVIDIA Triton Inference Server.

Key features include:
- GPU Planner: dynamically adds and removes GPUs to adjust to fluctuating user demand
- Smart Router: LLM-aware router that directs requests across large GPU fleets to minimize costly recomputations
- Low-Latency Communication Library: inference-optimized library supporting state-of-the-art GPU-to-GPU communication
- Memory Manager: intelligently offloads and reloads inference data to/from lower-cost memory and storage devices

NVIDIA Dynamo supports PyTorch, SGLang, NVIDIA TensorRT-LLM, and vLLM. It uses disaggregated serving to separate the processing and generation phases of LLMs on different GPUs.

Performance claims: doubles performance and revenue for Llama models on NVIDIA Hopper platform; boosts tokens generated by over 30x per GPU when running DeepSeek-R1 on GB200 NVL72 racks.

NVIDIA Dynamo will be made available in NVIDIA NIM microservices and supported in a future release by the NVIDIA AI Enterprise software platform.
