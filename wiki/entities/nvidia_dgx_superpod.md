# NVIDIA DGX SuperPOD

NVIDIA DGX SuperPOD is an enterprise AI infrastructure platform built with NVIDIA Blackwell Ultra GPUs. It provides out-of-the-box AI supercomputing for AI factories, enabling state-of-the-art agentic AI reasoning. DGX SuperPOD with DGX GB300 systems can scale up to tens of thousands of NVIDIA Grace Blackwell Ultra Superchips connected via NVIDIA NVLink, NVIDIA Quantum-X800 InfiniBand, and NVIDIA Spectrum-X Ethernet networking.
